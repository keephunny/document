基础地理实体可分为自然地理实体、人工地理实体和管理地理实体三大类。
* 自然地理实体重在表示自然生成或生长的地理实体，它包括山体、水体、冰雪地、海洋、农林用地与其他土地等地理实体。
* 人工地理实体重在表示人类建造或改造的地理实体，它包括水利、交通、建（构）筑物及设施、管线、院落等地理实体。
* 管理地理实体是政府治理社会，管理土地、资源与环境的政策和法规在地理空间上的的具体体现，它包括行政区划单元、地名、国土空间规划单元、其他管理区域等地理实体。


自然实体和人工实体客观存在，在现实世界中看得见、摸得着;管理实体是主观存在，在现实世界中看不见、摸不着。
自然地理实体和人工地理实体可作为各实体的空间定位框架和分析基础，管理地理实体重在表示重要管理需求所对应的地理实体，它所蕴含的内容可同时作为自然地理实体和人工地理实体的属性。基础地理实体数据库是新型基础测绘产品体系中的核心成果。
基础地理实体数据的内容更详细、更全面，可以人机兼容理解。其中，自然地理实体和人工地理实体都是客观存在的实体，但实体之间有关系、可组合！属性可修改、可扩充；管理地理实体是主观设置的实体，可改造、可扩展。
基础地理实体数据库侧重于地理信息的管理，主要服务于地理信息的查询、统计和分析。
