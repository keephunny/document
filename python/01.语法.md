```
#!/usr/bin/python3

if 条件表达式:
    条件语句
elif 条件表达式:
    条件语句
else :
    条件语句

示例：
var1 = 100
if var1:
    print ("1 - if 表达式条件为 true")
    print (var1)
 
var2 = 0
if var2:
    print ("2 - if 表达式条件为 true")
    print (var2)
print ("Good bye!")
```
